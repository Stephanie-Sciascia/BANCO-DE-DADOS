# BANCO DE DADOS

Este portfólio apresenta conceitos e atividades relacionadas à criação e organização de banco de dados.

## Objetivo

Aprender a estruturar e organizar banco de dados ultilizando:

- DER (Diagrama Entidade-Relacionamento)
- BRModelo
- Entidades e atributos
- Relacionamentos
- Chaves primárias e estrangeiras
- Normalização
- 1ª Forma Normal (1FN)
- 2ª Forma Normal (2FN)
- 3ª Forma Normal (3FN)

## Organização

- der/: diagramas Entidade-Relacionamento
- brmodelo/: modelos desenvolvidos no BRModelo
- normalizacao/: exemplos das 1FN, 2FN e 3 FN
- atividades/: exercícios e atividades realizadas
- projetos/: projetos de banco de dados 

## Ferramentas ultilizadas:

- BRModelo
- Modelagem de banco de dados
- DER
